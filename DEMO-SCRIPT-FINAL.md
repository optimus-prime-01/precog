"Double click karo — Entity Detail Panel khulta hai. Yahan dekh sakte ho NVIDIA ke saare events, connections, aur sabse important — kis source se ye data aaya.

## SCENE 4: Predictions (1:20 - 1:50)
**[Click Predictions tab on right sidebar]**

Ye dekho — 85% confidence ke saath predict kar raha hai ki enterprise AI infrastructure GPU pooling ki taraf shift hogi.

"Click karo — full reasoning dikhta hai. Kaunse signals converge hue, kya timeframe expect hai."

## SCENE 5: Contradictions (1:50 - 2:10)
**[Click Contradictions tab]**

"Jab do sources alag alag cheez bolte hain, PRECOG automatically detect karta hai.

Yahan dekho — Source A ek cheez bol raha hai, Source B doosri. System temporal analysis karta hai — kaunsa newer hai, kya severity hai.

No other knowledge graph tool does this. Baaki sab silently purana data overwrite kar dete hain. PRECOG conflict flag karta hai."

"Ab query karte hain — 'What happens if NVIDIA loses GPU market share to AMD?'

System pehle graph check karta hai — relevant data hai ya nahi. Agar nahi hai toh automatically web scrape karta hai, graph enrich karta hai, aur phir answer deta hai.

Answer mein specific entities, events, aur causal chains cited hain with confidence scores. Ye ChatGPT nahi hai — ye structured reasoning hai over a live knowledge graph."
